# 🐾 ხრამუნა (Khramuna) — გაყიდვებისა და კონსულტაციის ავტომატიზაცია

ეს არის სრულად დამოუკიდებელი (No Make.com needed), ქართულენოვანი ავტომატიზაციის სერვისი Facebook Messenger-ისთვის, რომელიც შექმნილია სპეციალურად ძაღლის ნატურალური სასუსნავების ბრენდისთვის — **„ხრამუნა“**.

---

## 🚀 ფუნქციონალი

1. **ჭკვიანი AI კონსულტანტი (Gemini):**
   - ზედმიწევნით იცის 4-ვე პროდუქტი („დრაკონის თათები“, „ღრუბელი“, „სუპერ-კუბები“, „ჯადოსნური პუდრა“) და Full Pack ნაკრები.
   - ითვალისწინებს ძაღლის ალერგიებს (ქათამზე ალერგიისას მკაცრად ურჩევს საქონლის პროდუქტებს).
   - იცის მიტანის ტარიფები და Waitlist-ის 10%-იანი ფასდაკლების ლოგიკა.
2. **შეკვეთის ავტომატური მიღება:**
   - ჩატში თავაზიანად აგროვებს: კლიენტის სახელს, ნომერს, მისამართს, პროდუქციას და მიტანის ტიპს.
3. **შეტყობინება Telegram-ში:**
   - შეკვეთის დაფიქსირებისთანავე მფლობელს/კურიერს მომენტალურად მისდის შეტყობინება სრული დეტალებით.
4. **შეკვეთების ლოკალური ბაზა:**
   - ინახება `data/orders.json`-ში და ხელმისაწვდომია `GET /api/orders` ენდფოინთზე.

## 🛠️ სწრაფი გაშვება და ტესტირება

### 1. დამოკიდებულებების დაყენება:
```bash
npm install
```

### 2. სერვერის გაშვება:
```bash
npm run dev
```

### 3. ადგილზევე გატესტვა (Facebook-ის გარეშეც):
შეგიძლიათ გატესტოთ ჩატბოტი ნებისმიერი HTTP მოთხოვნით:
```bash
curl -X POST http://localhost:3000/api/test-chat \
  -H "Content-Type: application/json" \
  -d "{\"message\": \"ჩემს ძაღლს ალერგია აქვს ქათამზე, რას მირჩევთ?\"}"
```

## 🔑 გასაღებების კონფიგურაცია (`.env`)

1. **Gemini API Key:**
   - შედით [Google AI Studio](https://aistudio.google.com/) და აიღეთ უფასო გასაღები.
   - ჩაწერეთ `.env`-ში: `GEMINI_API_KEY=...`

2. **Telegram შეტყობინებები:**
   - შექმენით ბოტი Telegram-ში: `@BotFather` -> `/newbot` და მიიღეთ `TELEGRAM_BOT_TOKEN`.
   - გაიგეთ თქვენი `TELEGRAM_CHAT_ID` ბოტით `@userinfobot`.

3. **Facebook (Meta for Developers):**
   - შედით [developers.facebook.com](https://developers.facebook.com)
   - შექმენით App (ტიპი: Business / Other)
   - დაამატეთ პროდუქტი **Messenger**
   - დააკავშირეთ თქვენი გვერდი **„ხრამუნა“** და დააგენერირეთ **Page Access Token** -> ჩაწერეთ `FB_PAGE_ACCESS_TOKEN`-ში.
   - Webhook-ის ველში მიუთითეთ:
     - **Callback URL:** `https://your-domain.com/webhook`
     - **Verify Token:** `khramuna_secret_verify_token` (რაც წერია `.env`-ში)
     - გამოიწერეთ `messages` და `messaging_postbacks`.
